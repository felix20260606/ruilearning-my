安装（Chrome / Brave / Edge）
1. 解压得到「双语字幕」文件夹（不要删除，插件一直引用它）
2. 打开 chrome://extensions（Brave 为 brave://extensions），开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择该文件夹；更新后点「重新加载」，再刷新 YouTube / B 站页面

支持的网站
- YouTube（www.youtube.com/watch）
- 哔哩哔哩（www.bilibili.com/video/…，含分 P；番剧页 bangumi/play/… 尽量支持）：用视频自带的 CC 字幕，英文优先（人工字幕 → 「英语（自动生成）」AI 字幕）。
  · B 站的 AI 字幕要登录 B 站才给；没登录时只有上传者自己传的 CC 字幕。拿不到字幕时播放器上和字幕栏里会说明原因。
  · 很多 B 站英文视频的字幕是烧在画面里的硬字幕，插件拿不到；可以用字幕栏顶部 📄 载入 .srt / .vtt / .ass 字幕文件。
  · 翻译默认用视频自带的中文字幕（人工的当人工翻译，AI 中文字幕当机器翻译），没有的句子再用翻译引擎补。
  · 保存的词句「出处」链接回 B 站这一集、从这句开始播。B 站视频的字幕不传网站「🎬 视频」页（那里只能放 YouTube）。

在中国大陆
- 谷歌翻译 / 谷歌发音 / 维基词典连不上时自动换备用，并记住哪个不通（6 小时内不再白等）：
  · 翻译：谷歌 → 微软翻译（Edge 浏览器里可用）→ 网站后台 → MyMemory（免费，每天有额度）
  · 查词：谷歌 → 有道词典（中文释义、音标、英文释义）；维基词典 → 网站后台中转 → 有道
  · 发音：谷歌 → 有道真人发音（单词）→ 浏览器自带语音
- 同步生词本、插件数据要连网站 *.pages.dev，大陆多数地方打不开；要换成自己的域名后才能同步（换之前查词、字幕照常，只是不同步）。

在哪里操作
- 播放器控制条：图标 = 开/关插件，齿轮 = 设置
- 播放器左侧：下一句 / 重播 / 上一句；右侧：AP 自动暂停开关、上下箭头（拖动移动字幕，单击隐藏/显示控件）
- 视频右侧字幕栏：字幕 / 词语 / 已保存；顶部 📄 载入字幕文件、↻ 修复、⤓ 导出、⚙ 设置、✕ 收起（默认视图收成「字幕（隐藏）」一条，影院 / 全屏时整块藏起来；用视频右侧的 ☰ 再展开。影院模式和全屏时字幕栏在视频右侧，视频让位，和 LR 一样）
- 单词：悬停或左键 = 查词典；右键 = 没有框的词直接加入「将要学习」，已在学习的词标为「已掌握」；卡片里可标记「不学习」

快捷键
A 上一个  S 重复  D 下一个  Space 播放/暂停  Q 自动暂停  R 保存当前字幕
Ctrl/⌘+C 复制当前句子  E 显示被隐藏的翻译  O 单句循环  Z/X 减速/加速
（L、T 等 YouTube 自带快捷键不占用；B 站的 D 键（弹幕开关）被「下一句」占用，可以点播放器下方的弹幕按钮）
（可在设置里开启「覆盖方向键」：← 上一句 ↓ 重复 → 下一句）

说明
- 「将要学习」的词会同步到生词本网站的待整理队列；在「已保存」标签底部可以看到并复制整个队列
- 导出：打印版 HTML、Excel（.xlsx）、已保存项目（.xlsx）
- 不要和 Language Reactor 同时启用，两者会叠在一起
- 词频表来自 OpenSubtitles 字幕语料（hermitdave/FrequencyWords，CC-BY-SA-4.0）
- 想让单词着色接近 Language Reactor：词汇水平选 700，比率选 2.0x
- 语法下划线（时态、被动、复数、冠词等）可在设置里整体或逐类开关
- 学习注释：字幕下面的小标签提示句型、习语、短语动词、搭配、口语缩略、语气词、连读；悬停单词显示原形、易混、语域、英美差异、发音、近义、构词、难度等；还有填空模式。设置「学习注释」里可分别开关
- 生词本网站：https://ruilearning-my.pages.dev（插件已内置这个地址，不用配置文件、不用口令）
- 更详细的说明见仓库根目录的 README.md
