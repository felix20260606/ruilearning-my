# ruilearning-my

个人学习站和英语学习插件。插件在看 YouTube / 哔哩哔哩时显示双语字幕、查词、收集生词（B 站见下文「[哔哩哔哩](#哔哩哔哩)」，中国大陆见「[在中国大陆](#在中国大陆)」）；网站（Cloudflare Pages）放生词本、看视频学英语，以及减脂、旅游等页面。

2026-11-18 由网站和插件两个仓库合并而成，两边的提交历史都保留了。原来的插件仓库已删除，**网站和插件都只在这个仓库里维护**，这里永远是最新版。

**部署、后台接口、备份与还原、插件更新、迁移记录、待办等流程，见 [流程说明.md](流程说明.md)。**

| 目录 | 内容 |
|---|---|
| `web/` | 网站，部署到 <https://ruilearning-my.pages.dev>（生词本、🎬 视频、减脂、旅游等；后台接口 `_worker.js`）。本地说明见 `web/README.txt`。全站界面统一用 `web/theme.css`（深色 + 紫色，和插件同一套配色） |
| `extension/` | 浏览器插件「双语字幕 · 生词收集」（图标为 BAN）（Manifest V3，Chrome / Brave / Edge） |
| `web/vs/` | 插件和网站共用的上色、语法、句型、注释模块（`bash tools/sync-shared.sh` 从 `extension/` 复制，别直接改） |
| `tools/` | 小工具：`sync-shared.sh`（同步共用模块）、`update-channels.py`（更新频道地图）、`gen-tts.mjs`（预先生成全站 AI 真人语音） |
| `site/` | 书签小工具的源码 `bookmarklet.src.js` 和安装页 `install-bookmarklet.html` |
| `tests/` | Playwright 回归测试脚本（加载插件 + 模拟的 YouTube 页面）和 Node 单测 |
| `data/` | 自动备份：`vocab.json`（生词本）、`captions/`（视频字幕），由 `.github/workflows/backup-vocab.yml` 每 6 小时更新 |

插件的使用习惯对齐 Language Reactor（下文简称 LR）：功能和操作方式一致，代码、图标、名称都是自己的，不使用 LR 的服务器。

## 安装与更新

1. 打开 `chrome://extensions`（Brave 为 `brave://extensions`），右上角开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择 `extension/` 文件夹。这个文件夹不能删，插件一直引用它。
3. 打开任意 YouTube 视频或 B 站视频，播放器控制条上出现「BAN ON」图标就是装好了。B 站要先在浏览器里登录，不然拿不到 AI 字幕。

更新：覆盖 `extension/` 里的文件后，在扩展页点插件卡片上的「重新加载」，再刷新 YouTube / B 站页面。已经开着的视频页不刷新也能继续用，但用的是旧版本。

不要和 Language Reactor 同时启用，两套字幕会叠在一起。

**只用插件、不用网站**：只需要 `extension/` 这一个文件夹（可以从 GitHub 下载整个仓库后单独拷出来）。插件会把生词同步到上面那个生词本网站、把看过的视频字幕传上去；双语字幕、查词、标记、复习、导出都不依赖网站。不想上传字幕，在设置里关掉「看过的视频字幕同步到生词本网站」。

## 字幕

### 来源

- **原文**：YouTube 自带的字幕轨。插件在页面里拦截 YouTube 自己发出的字幕请求，拿到带令牌的地址后改成 JSON 格式重新取一次。所以视频必须有字幕（人工的或自动生成的都行），并且 CC 要处于可用状态；插件会自动尝试打开 CC。
- **翻译**：默认用 YouTube 的自动翻译（和 LR 的来源相同）。可在设置里换成 Google 翻译或微软翻译。
- **视频没有学习语言的字幕轨时**（例如中文视频只有中文字幕）：和 LR 一样，让 YouTube 把现有字幕自动翻译成学习语言当作原文；如果现有字幕正好是翻译语言，就直接把它当翻译行。
- **人工翻译**：视频自带目标语言的人工字幕时，可以另外显示一行。

### 哔哩哔哩

插件 1.25.0 起支持 `www.bilibili.com/video/…`（分 P、页内换视频都跟着变）和番剧页，功能和 YouTube 一样：双语字幕、悬停 / 点击查词、右侧字幕栏、单句循环、收词、单词颜色。

- **原文**：视频的 CC 字幕。先用英文人工字幕，没有再用「英语（自动生成）」AI 字幕。B 站常有标错语言的字幕轨（标成英语其实是中文），插件会按内容核对一遍。
- **翻译**：先用视频自带的中文字幕（人工中文当人工翻译，AI 中文当「视频自带翻译」），不用连任何翻译服务；没有才用翻译引擎。
- **拿不到字幕时会说明原因**：没登录（AI 字幕要登录）、只有别的语言、或者没有 CC 字幕（多半是烧在画面里的硬字幕，可以用 📄 载入字幕文件）。
- **出处**：保存的词句链接回 B 站这一 P 的这一秒（如 `https://www.bilibili.com/video/BV1Gf4y1y7wc/?p=4&t=17`）；网站「⭐ 已保存」里的「🎬 原视频」也直接打开 B 站。
- 插件开着时 B 站自己的 CC 字幕会隐藏，避免叠两层。字幕栏在视频右侧的栏里，网页全屏 / 全屏时放在视频右边。
- B 站的字幕不上传到网站（网站「🎬 视频」只能放 YouTube）。
- B 站原来用 `D` 键开关弹幕，插件开着时 `D` 是「下一句」。

### 在中国大陆

插件的每个外部请求都有超时；连不上的服务记 6 小时，期间直接用备用的，不再白等。

| 用途 | 先用 | 不通时依次用 |
|---|---|---|
| 句子翻译 | 谷歌翻译 | 微软翻译 → 网站后台翻译 → MyMemory |
| 查词中文 | 谷歌 | 有道词典（国内服务）→ 网站后台词典 |
| 英文释义、原形、固定短语 | 维基词典 | 网站中转 → 有道词典（柯林斯、WordNet 释义） |
| 发音 | 谷歌词典录音 / 谷歌朗读 | 有道真人发音（只有单词）→ 浏览器自带语音 |

- 微软翻译取令牌的接口在 Chrome / Brave 里返回 404，大概只有 Edge 能用；所以在 Chrome / Brave 里，谷歌不通时整句翻译主要靠 MyMemory，它每天每个 IP 大约 5000 字（差不多一个视频），用完当天就翻不出来。看 B 站时尽量用视频自带的中文字幕。
- 网站 `*.pages.dev` 在大陆多数地方打不开：同步生词本、网站后台翻译 / 词典 / 中转都靠它，要换成自己的域名才行（代码解决不了）。换之前字幕、查词、发音照常，只是不同步。
- 技术细节（接口地址、挑轨规则、页面加载时机）见 [流程说明.md](流程说明.md)「插件在 B 站和中国大陆」。

### 文本处理

- 清理 HTML 实体、零宽字符、`>>` 说话人标记；`--` 换成破折号；直引号换成弯引号。
- `(Laughter)`、`[Music]` 这类提示单独标成注释行，最长显示 2 秒。
- 自动生成的字幕（ASR）每行很短，会把相邻两行配成一句（间隔小于 1.5 秒、总长小于 110 字符）。
- 可选「按整句合并字幕」：把被拆成几行的一句话合成一条。
- 中文翻译里汉字之间多余的空格会去掉。

### 显示时机

- 一句结束后字幕不消失，停在当前句，直到下一句开始才切换。
- 开着自动暂停时，暂停点在句末前约 0.12 秒；暂停期间锁定当前句，不会提前显示下一句。

### 隐藏字幕（练听力用）

设置里的「隐藏字幕」有五个选项：禁用、隐藏翻译、隐藏字幕、先显示翻译再显示字幕、先显示字幕再显示翻译。

- 被隐藏的行模糊显示。
- 暂停不会自动显示。
- 鼠标移到或点击某一行，只显示那一行，这一句内保持显示。
- 按 `E` 按模式的顺序逐行显示。
- 换到下一句重新隐藏。

## 查词

### 悬停：小气泡

- 两三个中文释义。
- 词频条：越长越生僻。
- 短语：如果这个词和前后词组成短语（如 `a week later`、`two weeks`、`got it`），先显示短语和它的翻译。短语靠 Wiktionary 是否有这个词条，加上一组时间短语规则来判断。
- 不规则变形：显示原形及释义（`wrote` → `write`）。
- 缩写：先展开再翻译（`I'd` → `I would`）。
- 语法：带语法下划线的词会多一行说明，如「语法：过去时」。
- 可选「显示迷你词典时自动暂停」：悬停时暂停视频，移开后继续。

每句字幕出现时，会提前把这一句里的生词查好，悬停时直接显示。查过的词存在本地，下次不用联网。查询失败不会被记住，下次悬停会重查；插件后台连不上时，页面会自己直接查。

### 点击：词典面板

停靠在播放器右侧，包含：

- 单词、音标（Datamuse 的发音数据转成 IPA）、朗读。
- 中文释义按词性分组，英文释义来自 Wiktionary。
- 词频条和词频排名。
- 标记按钮：✓ 已掌握、📖 将要学习、⊘ 不学习。
- 外部词典链接：Reverso、Cambridge、WordReference、Google、Wiktionary、百度，以及你在设置里加的自定义网址。
- 「示例：当前文本」：这个词在本视频里出现的句子，可以点播放、收藏。
- 面板里的单词同样可以悬停、点击、右键标记。

### 右键：标记

- 没有框的词：右键直接加入「将要学习」。
- 已经在学习的词（黄框）：右键标为「已掌握」。

- **短语一起保存**：把一个词加入学习时，如果它在一个短语里（如 a week later、got it），这个短语连同所在的原句、原声、画面和出处一起存进「保存的短语」，并进入待整理队列。可在设置里关掉。

## 单词颜色与词汇水平

在设置里点「设置词汇水平与单词颜色」，选择你大约认识多少个常用词（词汇水平）和「建议学习」的范围比率。

| 类别 | 判断方式 | 默认显示 |
|---|---|---|
| 已掌握 | 词频排名在你的水平以内，或手动标记 | 白色（可选绿色） |
| 建议学习 | 排名在「水平」到「水平 + max(水平, 300) × 比率」之间 | 橙色 |
| 更生僻 | 排名超出建议范围 | 紫色 |
| 将要学习 | 你右键或在词典里标记的词 | 淡黄色框 |
| 不学习 | 手动标记 | 紫色 |
| 特殊词汇 | 数字、数词、全大写缩写、句中首字母大写的人名地名 | 绿色 |

- **你自己的标记按原形生效**：保存了 write，字幕里的 wrote、written、writes 也带黄框；标 going 为已掌握，go、went 也算已掌握。词频表里查不到原形的生僻词（如 reinvented）按词尾规则归并。「所有单词」页只列原形，用的是和字幕上色同一个判断函数，两边状态一致。
- 词频表是 OpenSubtitles 字幕语料的前 22000 个词，按原形判断难度（`papers` 按 `paper` 算）。
- 想让着色接近 LR：水平选 700，比率选 2.0x。在同一个 TED 视频上和 LR 对比，624 个不同的词里 93% 颜色一致。

## 语法下划线

把英语里中文没有或很少有的形式用下划线标出来。这是 LR 没有的功能。

| 下划线 | 含义 | 英文 | 缩写 | 例子 |
|---|---|---|---|---|
| 蓝色实线 | 过去时 | Past simple | pt | wrote、turned、were |
| 青色双线 | 完成时 | Perfect | perf. | have written、having written |
| 绿色波浪线 | 进行时 | Continuous | cont. | is working |
| 粉色虚线 | 将来 / 情态 | Modal verb | modal | will、would、is going to |
| 橙红粗线 | 被动语态 | Passive | pass. | was written、are supposed |
| 蓝色点线 | 第三人称单数 | 3rd person singular | 3rd sg. | writes、doesn't |
| 灰色点线 | 复数 | Plural | pl. | months、words |
| 黄色点线 | 冠词 | Article | art. | a、the |
| 紫色虚线 | 比较级 / 最高级 | Comparative / Superlative | comp. | bigger、most |
| 词上方红线 | 否定缩写 | Negative contraction | neg. | didn't |

- 字幕和右侧栏里都会标，和单词颜色互不影响。
- 设置里有总开关，十类也可以各自单独开关；每一行同时列出中文名、英文名和缩写。
- **下划线下方的标识**：视频上的字幕会在下划线下面用小字标出是哪一类，颜色和下划线一致。设置里可选「缩写（pt、pl.…）/ 中文（过去、复数…）/ 英文（past、plural…）/ 不显示」，默认缩写。只标在视频字幕里，右侧栏不标；`has written` 这种一组词只标在第一个词下面。英文模式的标识较长，遇到很短的词（如 `a bigger`）会挤在一起。
- 缩写用的是英语教材和学习词典里常见的写法（pt、pl.、comp. 来自牛津学习词典的惯例），不是语言学论文用的 PST / PRF / PROG 那一套。`will` 和 `would` 都归在 modal 下。
- 判断靠词形、一张不规则动词表和前后几个词，不是真正的语法分析，会有少量标错。最容易错的是 -ed 结尾的形容词被当成过去时，以及 -s 结尾的词在复数和第三人称单数之间判错。
- 一个词只标一种时态：`have been working` 里 `have been` 标完成时，`working` 标进行时。

## 学习注释

视频字幕下面用一排小标签提示这句里值得学的东西，每句最多 5 个；鼠标移到标签上，句子里对应的词会高亮，旁边浮出讲解和例句（不占位置，不会把字幕顶出视频）；点一下固定显示。

| 标签 | 内容 | 数据 |
|---|---|---|
| 📐 句型 | 80 多个：There be、It is … to do、倒装、强调句、反义疑问句、间接疑问句、虚拟（If … would、suggest that、Were I…）、定语从句、What … is、分词短语开头、祈使句 + or、倍数比较、口语结构（There's no point、end up、How come…）、get 被动、have sth done、简短回应（Me too / I hope not）等 | `extension/pattern.js` |
| 🧩 习语 · 🔗 短语动词 · 🤝 搭配 | piece of cake、figure out（拆开的 figure it out 也认）、make a decision 等，搭配会提示中式错误 | `extension/data-phrases.js` |
| 💬 口语缩略 · 💭 语气词 | gonna = going to、y'all；you know / I mean / like 等填充词（只在被逗号隔开或句首时算） | `extension/data-morph.js` |
| 🔊 连读 | want to → wanna、did you → didja 等 | `extension/data-morph.js` |

单词注释显示在悬停小窗（最重要的 3 条）和点词后的词典里（全部）：原形和变化、口语缩略、中式英语易混、语域（口语 / 书面 / 俚语 / 粗口）、可数性、缩写、英美差异、不发音字母、重音、弱读、近义词辨析、高级替换、词根词缀拆解、难度等级（按词频估计 A1–C2）、专有名词的维基百科链接。数据在 `extension/data-words.js` 和 `extension/data-morph.js`，直接增删行即可。

**填空模式**：设置里打开后，字幕里高于你水平的生词先被遮住，听完把鼠标移上去看答案。

设置「学习注释」一栏可以分别关掉句型、习语/短语动词/搭配、口语、连读、单词注释。所有判断都靠词序和词表，不分析句子结构，偶尔会认错。

## 右侧栏：字幕 / 词语 / 已保存

顶部工具：📄 载入字幕文件、↻ 重新获取字幕、⤓ 导出、⚙ 设置、✕ 收起。

交互和 LR 的「垂直视图」一样（2026-11-18 在装了 LR 的浏览器里逐项对照过）：

- 视频画面右边缘的 ☰ 图标（鼠标移到视频上才出现）：打开字幕栏；字幕栏打开时这个图标隐藏。字幕栏右上角 ✕：收起。默认视图下收成右侧栏里的「字幕（隐藏）」一条（点一下展开）；影院模式、全屏时整块藏起来，不留东西。
- **默认视图**：字幕栏在视频右侧的栏里，和视频一样高。
- **影院模式、全屏**：字幕栏放进视频区域的右侧（宽 400 像素、和视频一样高），视频自动缩窄让位；收起后视频恢复全宽。切换影院 / 全屏时会自动换位置。
- 想彻底不显示，在设置里关掉「显示字幕列表视图」。

### 字幕

- 每行只显示原文，当前句高亮并自动滚动到中间。
- 翻译的显示方式可在设置里选：「悬停时弹框显示」（默认，和 LR 一样）或「显示在列表里」（每行原文下面直接带翻译，这时气泡只显示单词和短语）。
- 悬停一行：左边出现播放按钮，右边出现 ☆（保存这句）。
- 悬停单词：气泡出现在侧栏左侧，依次是短语、单词释义（带词频条）、语法、整句翻译。悬停行内空白处只显示整句翻译。
- 点击单词开词典；点击行或播放按钮跳到那一句。
- 手动滚动后停止自动跟随，右上角出现紫色圆形按钮，点它回到当前句并恢复跟随。

### 词语

三个视图：

- **学习**：进度条「你已掌握 X% 的单词」和「学习 20 个单词即可达到 Y%」。按 0–10 min、10–20 min 分段列出推荐词，每个词有序号、出现次数、两个释义、📖 按钮，后面跟最多 6 句视频里的例句。底部有「标记为正在学习 (20)」和翻页。推荐顺序按「出现次数 ÷ 生僻程度」排，常用且出现多的排前面。
- **词频排名**：✓ 已掌握 / 📖 学习中 / ⊘ 不学 三个计数（点击可筛选）和总词数。按 Rank 1–100 … 8001+ 分段，段内按出现次数（100+、50+、20+、10+、5+、4、3、2、1）分组。
- **视频中出现次数**：只按出现次数分组，词多的组再按首字母分。

### 已保存

- 「查看全部」打开完整的已保存页面。
- 「最近保存」按时间倒序，单词标 `w`，句子标 `p`。
- 「显示上下文」开关：打开后单词显示保存时所在的那句话。旧的没有记录原句的词，会从当前视频里找一句包含它的句子补上。
- 最底部是「生词本待整理队列」，可以一键复制。

## 复习（网站「📖 生词本 → 🔊 练习」，代码 `web/pump.js`）

只有这一个复习入口：插件里的「复习 / 练习」按钮都打开它（插件自己的复习页 2026-11-20 已删除）。手机、电脑同一份进度（存在生词本 `vocab.srs`）。照 LR 的 PhrasePump 做，排程按遗忘曲线。

**练什么**：生词本里的单词、短语、句子、规律（已掌握的不练）；可按颜色标签筛选；可加「推荐生词」（从看过的视频里挑还没收的词，练了不记进度，想学点「＋ 收进生词本」）。

**测验、建议、练习、练习数量、新项目**（照 PhrasePump 服务器的挑卡规则；2026-11-20 读它返回的挑卡记录逐项对照过）
- 默认：测验、建议、练习都开，练习数量 60，新项目 15 %。改了任何一项，「会话」旁出现「重置」。
- 「练习数量」= 名额（卡片张数）。每个词占：听 3 句 = 3 张（整句 1 张）、填空 = 1 张、认词卡（我们加的）+1、建议 = 1 张。
- 四种模式，开关互不影响：
  - 测验 + 练习（混合）：每个词看复习记录，被动听过 2 轮出 1 道填空，不够就听。
  - 只开测验：只考不听，每个词 1 道填空（考不了的给认词卡）。
  - 只开练习：只听不考。
  - 都关：不复习任何词，只出「建议」（名额 = 练习数量 × 新项目）。
- 名额顺序：该复习的（最可能忘的先）→ 新词（最多 练习数量 × 新项目）→ 建议（用新词剩下的名额）→ 没到期的复习 → 「练习」开着时，用例句库的随机额外句子补满（`/api/sent?pump=`，不记进度）。
- 最后一个词放不下时：剩下的名额够它一半就照样放（所以选 60 有时是 61 张），不够就停。首页显示的就是实际张数。

**和 RL 对齐的细节**（2026-11-20 逐条对照 RL 网页程序）
- 练的范围：保存的单词、短语、句子都练（「规律」类可在「类型」里加）。认词卡是我们加的，默认关（RL 没有）。
- 被动听按张数算：每张听力卡算一次，一个词被动听过 2 次就改成测验（第一轮听完 3 句，下一轮就考）。
- ☆ / R 键：收藏当前这句（存进插件的「收藏的句子」，生词本里加一条句子词条），再按一次取消。
- 右上角：⌨ 快捷键说明；播放速度 1x → 0.75x → 0.5x（原声和朗读都变）。
- 卡片右下角鼠标停上去：例句出处（保存于 YouTube 的视频 / Tatoeba CC-BY / 额外练习句子 / 生词本例句）。

**一个词这一轮怎么练**（同 PhrasePump）
- 前两轮：认词卡（看英文想中文 / 看中文想英文，翻开后自己判断认识与否）+ 3 句听力。听力例句 = 词条自带的例句 + Tatoeba 例句库（`/api/sent`，后台缓存 30 天），每次换着听，最近听过的往后排。
- 被动听过 2 轮之后：改成 1 道填空，用保存时的原句。
- 从视频里收的词，练到保存时那句：显示两张视频画面、播放原声；视频带人工翻译时 H（人工）/ M（机器）两行对照。
- 句子按词汇水平上色、带语法下划线（和视频字幕、插件一样），目标词带框。

**排程：Ebisu（同 Language Reactor 默认的 EBISU 排程；公式照 Ebisu 2.1 官方库 github.com/fasiha/ebisu）**
- 每个词一个模型 `[α, β, t]`（存在 `vocab.srs` 的 `e`），由它算出「现在记得的概率」和「半衰期」`h`（记得的概率降到 50% 的天数），和 LR 存的字段一样。
- 新词：Ebisu 默认 α = β = 3，半衰期先按 1 天（第一轮就忘了的按 6 小时）。
- 记得的概率降到 50%（过了半衰期）该复习，降到 30% 算紧急；挑卡时最可能忘的先练。
- 这一轮都对：按「记得」更新，半衰期变长——越接近遗忘时答对涨得越多，提前复习几乎不涨；有一张忘了：按「忘了」更新，半衰期变短。
- 半衰期到 42 天（LR：「至少 6 周都很可能记得」）自动标为「已掌握」。Ebisu 默认参数比较保守：一直答对大约要练 18 轮、半年左右（LR 上也是这样，171 个在学只有 4 个已学习）。
- LR 服务器上的具体参数（新词初始值、紧急的门槛）网页里看不到，上面这几个数是按 Ebisu 官方默认值和 LR 的说明定的。
- 旧进度（级别 b、之前 FSRS 的稳定度 s）当作半衰期换算成 Ebisu 模型接着算。
- 掌握进度 = ln(1 + 半衰期) / ln(43)：1 天 ≈ 18 %，7 天 ≈ 55 %，14 天 ≈ 72 %，42 天 = 100 %。

**导出**（练习页右上角 ⚙，代码 `web/export.js`，只读）：可选范围（全部 / 未掌握 / 已掌握）和是否带截图·配图、原声。
- 📇 Anki：ZIP（`生词本.txt` 带 `#separator:tab` `#html:true` 头 + `media/` + 导入说明）；正面单词、音标、截图、原声，背面中文、释义、词形、例句、记忆法。
- 📊 表格 CSV：Excel 能打开；带媒体时打成 ZIP，表格里写 `media/` 下的文件名。
- 🌐 离线网页：单个 .html，图片和原声用 data URL 内嵌，带搜索。
- 🗄 完整备份 JSON：词条 + 复习进度 + base64 媒体。
- 📋 复制成文字。
- 媒体来源：`/api/ext` 的原声截图索引 + `/api/media`；没有截图的用维基配图（取不到就跳过）。原声是 webm，iPhone 版 Anki 可能放不了。

**键盘**：A 上一个、S 重听、E 显示 / 翻开、D 下一个；认词卡翻开后 1 不认识、2 认识。

## 与 Language Reactor 的对比

在同一个视频上并排对比过的结果：

| 项目 | 结果 |
|---|---|
| 人工字幕视频：原文分句 | 38 句里 37 句一致 |
| 人工字幕视频：翻译 | 38 句里 36 句一致 |
| 人工字幕视频：单词颜色 | 260 个词里 251 个一致 |
| 自动字幕视频：原文分句 | 20 句里 17 句一致 |
| 词语页「已掌握」比例 | LR 83%，本插件 84% |
| 自动暂停时显示的句子 | 连续 7 句与 LR 相同 |

行为已对齐的部分：字幕位置和控件布局、隐藏字幕的五种模式、悬停气泡和点击词典、侧栏三个标签页、☰ / ✕ 打开收起字幕栏（影院模式和全屏时在视频右侧，视频让位，同 LR 垂直视图）、回到当前句按钮、快捷键、右键标记。收起后默认视图留「字幕（隐藏）」一条、影院 / 全屏不留，也和 LR 一致。

没有做的：

- 词频排名里的四个彩色 `#` 标签。
- 字幕行右侧的 `⋮` 菜单。
- Netflix 等其他网站（YouTube 之外只做了哔哩哔哩）。

仍有差别的：

- 个别单词的中文释义用词不同（词典数据不是同一份）。
- 约 4%–7% 的单词颜色不同（词频数据不是同一份）。
- 词频排名的总词数偏多（词形归并不如 LR 细，如 `going` 和 `go` 算成两个词）。
- 自动字幕里音乐提示和说话的先后顺序偶尔不同。

本插件比 LR 多的：语法下划线、生词本待整理队列同步、自定义翻译引擎。

内容脚本的加载顺序：`inject.js`（YouTube）/ `bili-inject.js`（B 站）（主环境，文档开始时）→ `sites.js` → `freq.js` → `vlevel.js` → `gram.js` → `pattern.js` → 三个 `data-*.js` → `notes.js` → `content.js`。

### 关键流程

1. `inject.js` 给 `XMLHttpRequest` 和 `fetch` 打补丁，看到 `/api/timedtext` 请求就把地址发给内容脚本。
2. `content.js` 用这个地址加 `fmt=json3` 重新请求原文；加 `tlang=zh-Hans` 请求 YouTube 的自动翻译。
3. 解析、清理、分句，得到 `cues`（每条有开始时间、结束时间、文本）。
4. 每 100 毫秒检查一次播放位置，找到当前句并渲染；自动暂停临近句末时改用精确计时。
5. 渲染时文本依次经过 `vsMark`（颜色）和 `vsGramHtml`（下划线）。
6. 悬停和点击通过消息向 `background.js` 请求释义；后台不可用时内容脚本自己直接请求。

B 站：`content.js` 通过 `postMessage` 问 `bili-inject.js` 这个视频有哪些字幕（`bili-tracks`），按上文的规则挑轨，直接取字幕 JSON（`{body:[{from,to,content}]}`），之后第 3 步起和 YouTube 一样。和网站有关的代码都通过 `VS_SITE`，`content.js` 两个网站共用。

### 开发用的钩子

`content.js` 里留了三个给自动化测试和远程更新用的消息入口，正式发布前应删掉：

- `postMessage({src:'VS', type:'reload-ext'})`：让插件重新加载自己。
- `type:'dev-level'`：直接设置词汇水平和比率。
- `type:'dev-state'`：返回当前部分设置。

- 设置窗口、全屏、iPhone Safari 上的书签小工具没有在真实环境里核对过。

### 生词怎么同步

- 在视频里把单词标为「正在学习」（或保存短语）时，插件直接在网站后台生成一条完整词条：中文释义、音标、英文释义、视频原句及其翻译，标签为「视频」。
- 网站和插件用同一份生词本（KV 里的 `vocab` 这一条），打开网站会自动拉取，这些词立刻出现在列表和练习里。
- 网站「📖 生词本 → ⭐ 已保存」：装了插件的电脑直接嵌入插件的已保存页（插件的 `site.js` 告诉网页插件 ID，`manifest.json` 允许网站嵌入这一页），能编辑；手机和没装插件的浏览器显示网站只读版（`web/saved-web.js`）。
- 生词本「🔊 练习」模式（网站，手机电脑都能用）：PhrasePump 式练法，是唯一的复习入口（插件里的「复习」按钮也打开它；插件复习页 2026-11-20 已删除）。有认词卡（原来的背诵、自测）、截图、原声、推荐生词、标签筛选、人工 / 机器翻译对照。代码在 `web/pump.js`。
- 接口 `/api/vocab`：`GET` 读取整份生词本；`POST {state}` 由后台和云端合并后保存，返回合并结果（网站用）；`POST {add:[词条]}` 加入完整词条（插件用）；`POST {patch:{srs, progress}}` 只改复习进度和掌握状态（插件复习页每练一张卡发一次）。合并规则：两边取并集，同一个词条以新提交的为准，删除会同步到所有设备。
- 不设口令，打开网站就同步。
- KV 是最终一致的：在一台设备上的改动，另一台设备最多约一分钟后才能读到。两台设备在一分钟内改同一个词条时，后提交的为准。
- 设置页「词汇」一栏的 **同步到生词本网站 ›** 可以把本机已保存的词和云端「待整理队列」里的词一次补齐；更新后首次打开 YouTube 也会自动补齐一次。
- 连续加词时云端写入是串行的，不会互相覆盖；同名词条不会重复添加。
- 网站上的「已掌握」进度只在网站各设备间同步，不会反过来改插件里的标记。
- 「规律」类词条（语法、搭配、发音、词根、场景、主题词汇等，2026-11-20 共 192 条）按 `tag` 分 13 类：列表选「规律」后下面一排分类按钮，「📐 语法」页按栏目显示。分类表和加新规律的格式见 `流程说明.md`「生词本」一节。

### 家人（多用户）

不设密码，家里每个人各用一本生词本：网站生词本标题下「👤 名字 ▾」切换和添加家人；插件跟着网站走：在这台电脑上用网站「👤」切到谁，插件就自动同步给谁（切换前先把当前的人的数据传完，传不上去不切；插件设置「词汇 → 生词本用户（家人）」也能手动选）。生词本、练习进度、已保存、标记、录音截图各自分开；视频字幕和例句大家共用。实现、接口和测试见 `流程说明.md`「家人（多用户）」。

### 备份与还原

- **仓库备份**：GitHub Actions（`.github/workflows/backup-vocab.yml`）每 6 小时把线上生词本存成 `data/vocab.json`、视频字幕存进 `data/captions/`（只下新增或变化的视频；网站上删掉的视频备份里保留），有变化才提交。每个版本都在 Git 历史里，也可以在 Actions 页面点「Run workflow」立即备份一次。`data/` 不在 `web/` 里，不会触发网站部署。
- **后台存档**：每天第一次改动前，后台先把改动前的整份生词本存一份，保留 30 天。`GET /api/vocab?history=1` 列出有存档的日期，`GET /api/vocab?at=2026-11-18` 取那天的存档。
- **还原**：把要还原的那份内容整份写回去：`POST /api/vocab`，内容为 `{"replace": 备份内容}`。例如用仓库里的备份：
  `jq '{replace: .}' data/vocab.json | curl -X POST -H 'Content-Type: application/json' --data-binary @- https://ruilearning-my.pages.dev/api/vocab`
  还原后各设备打开网站会拿到还原后的内容；只是某台设备本机还留着被删的标记时，它下次同步会把这些标记再合并进去，所以还原后先在各设备上刷新一次网站。

### 视频字幕怎么同步

都通过网站上的一个接口 `/api/cap`：

| 动作 | 请求 | 说明 |
|---|---|---|
| 保存一个视频的字幕 | `POST` | 内容是视频 ID、标题、频道、每句的起止时间、原文、译文。接口存进 Cloudflare KV（目录信息放在每条记录的元数据里，新视频最多约一分钟后出现在目录中） |
| 取视频目录 | `GET ?list=1` | 返回已保存的视频列表（最多 300 个） |
| 取一个视频的字幕 | `GET ?v=<视频ID>` | 返回这个视频的全部字幕 |
| 删除 | `DELETE ?v=<视频ID>` | |

- 插件里已写好网站地址 `https://ruilearning-my.pages.dev`；`manifest.json` 已允许访问 `*.pages.dev`。
- **上传方**：插件在视频连续播放约 20 秒后上传，每个视频只传一次；暂停时、没有字幕时不传。设置里「看过的视频字幕同步到生词本网站」可关闭。
- **读取方**：网站打开「🎬 视频」时取目录，点开视频时取字幕。读取不需要密钥，所以手机上不用登录；这也意味着知道网址的人能读到这些字幕（只有公开视频的字幕和译文）。
- 没有译文的句子，网页会在浏览器里分批翻译并缓存在本机。

### 网站的「🎬 视频」（「📚 英语 → 🎧 听」里）

- 在「📚 英语 → 🎧 听 → 🎬 视频」（2026-11-21 以前是顶部一级标签），会记住上次停留的标签；`?go=video` 直达，`?v=视频ID` 直接打开某个视频。
- 首页：粘贴 YouTube 链接的输入框，和已同步视频的列表。粘贴链接只对已经存过字幕的视频有双语字幕，否则只能播放。
- **📺 频道通关地图**（在视频首页说明下面，可收起，记住展开状态）：41 个适合学英语的 YouTube 频道，按难度分 0基础 / 初阶 / 初中阶衔接 / 中阶 / 高阶，再按类型筛选（可理解输入、生活实用、小孩家庭、华语地区外国人、Vlog、对话·脱口秀·播客、兴趣）。每个频道有口音、男女声、主题和推荐理由；点频道名打开 YouTube，点「▶ 样片」在网站播放器里从推荐的时间点开始放。数据 `web/yt-channels.json` 整理自 Notion「用油管足不出户自学流利英文·频道通关推荐」，原清单更新后运行 `python3 tools/update-channels.py` 重新生成。
- 视频列表：按标题 / 频道搜索；排序（最近添加 / 最近观看 / 标题 / 时长）；筛选（全部 / ★收藏 / 在看 / 未看 / 看过，带数量）；每个视频显示时长、句数、译文完整度、观看进度条；顶部「继续上次」卡片；刷新按钮；列表为空时有添加视频的三种方法说明。
- 每个视频的「⋯」菜单：收藏（排最前）、标为看过 / 未看、删除（确认后从网站删除；字幕在仓库 `data/captions/` 有备份，可找回）。收藏、看过、进度只存在当前设备的浏览器里。
- 重新打开视频时从上次位置往前 2 秒继续，旁边有「从头开始」。
- 播放页占满一屏：YouTube 官方嵌入播放器、当前双语字幕、一排按钮（上句 / 重听 / 下句 / 逐句停 / 藏译文 / 变速），下面是可滚动的字幕列表，点任意一句跳过去，当前句高亮并自动跟随。
- 播放页新增：单句循环、A-B 区间循环、藏原文（练听力）、「更多」菜单（字号小 / 中 / 大、复制当前句、在 YouTube 从当前时间打开、复制视频链接、删除）。
- 电脑键盘快捷键：空格 / K 播放暂停，← → 上下句，R 重听，L 单句循环，B / E 设区间起点 / 终点，P 逐句停，T 藏译文，S 变速，C 复制本句，Esc 关菜单。点过视频画面后焦点在 YouTube 播放器里，快捷键会失灵，点一下页面空白处即可。
- 点字幕里的单词：底部弹出释义、音标、英文释义和原句，可发音，可一键加入生词本（带原句）。
- `/?v=<视频ID>` 可以直接打开某个视频。
- 做不到的：字幕叠在画面上、全屏时显示字幕、保存原声。

### 手机上不经过电脑：书签小工具

「🎬 视频」首页的「📱 手机上给任意视频加字幕」里有安装步骤和「复制书签代码」按钮。装好后：

1. 在手机浏览器（不是 YouTube App）里打开 YouTube 视频，点播放。
2. 点书签「学这个视频」。
3. 它在 YouTube 页面里读取播放器正在使用的字幕，再读一份 YouTube 自带的中文翻译轨，按时间对齐后存到网站，然后跳到 `/?v=<视频ID>`。

字幕里的特殊符号会清掉：说话人标记 `>>`、`[music]` 这类方括号说明、`♪`，以及整句只有 `(Laughter)` 这种括号说明的行。网页打开已存的字幕时也会做同样的清理。个别没对上中文的句子由网页在浏览器里补译；补译失败会显示提示和「重试」按钮，全部补齐后存回网站。

书签代码里没有口令，可以放心复制。它读的是 YouTube 正常加载给当前用户的字幕，和插件原理相同。

### 试过但走不通的路

- **网站后台直接向 YouTube 取字幕**：被拒绝（"Sign in to confirm you're not a bot"）。伪装成官方客户端去取属于绕过对方的防护，没有做。
- **手机浏览器里的网页直接取字幕**：被浏览器的跨域规则挡住。
- **让手机浏览器装这个插件**：手机版 Chrome、Safari、Brave 都不支持。

### 已知限制

- **YouTube 可能拦嵌入播放器**：嵌入的播放器是未登录状态，在被 YouTube 标记的网络上会弹「请登录以确认你不是机器人」，视频播不了，换一个网络（比如手机流量）即可。短时间内反复刷新 YouTube 的网络容易被标记。
- 少数视频禁止站外嵌入。
- 真实播放下的字幕跟随、逐句停只在电脑的模拟播放器测试里验证过；在 iPhone 流量下确认过视频能播放、同步的字幕能显示。
- 书签小工具在 iPhone Safari 上已能读到字幕并存到网站；带中文翻译轨的新版本只在电脑的 YouTube 页面上验证过（443 句里 435 句直接带中文）。
- 手机网络下，网页临时翻译的请求可能被翻译服务拒绝，所以译文尽量在上传时就带上。
