# 内蒙古 12 个盟市景点详细版（数据源）

每个盟市一个 `<后缀>.json`（如 `hulunbuir.json` → 城市页 `cn-city.html?c=neimenggu-hulunbuir`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web neimenggu tools/sights/neimenggu`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 呼和浩特的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从呼和浩特去」。东部的呼伦贝尔、兴安、通辽、赤峰在 `from_hz` 里先写飞机和从北京 / 沈阳 / 哈尔滨方向的走法（离呼和浩特太远）。
- 草原、沙漠、森林、湖泊类景点都写了最佳季节；距离远的写了自驾 / 包车的公里数和时间（OSRM 路网估算再上浮，写成「约 X 公里、X 小时左右」）。
- 交通按 2026-11 的情况写：
  - 呼和浩特盛乐国际机场（和林格尔县，离市中心约 40 公里）2026-11-26 零时转场投运，白塔机场同时关闭；新机场暂时没有地铁。
  - 呼和浩特地铁 1 号线（伊利健康谷—坝堰）、2 号线（塔利东路—阿尔山路），新华广场换乘。
  - 北京北 / 清河 → 呼和浩特东最快约 2 小时 9 分；呼和浩特东 → 包头最快约 1 小时 19 分；呼和浩特东 → 鄂尔多斯 C 字头城际约 2 小时 20 分（二等座约 ¥70）。
- 冬季闭园（2026-10-08 起）：黄花沟（拟 2027-05-01 开园）、岱海、元上都遗址（预计 2027 年 5 月）；兴安盟博物馆 2026-10-08 至 11-08 临时闭馆。携程上很多草原 / 沙漠景区 11 月显示「暂停营业」，都写成季节性开放、以官方为准。
- 门票：多是携程 / 大河票务的平台价，写成「约 ¥X（以官方为准）」；查不到的写「以现场为准」。
- 照片：Commons 网页搜索（中文名加引号、英文名 + 地名）找候选，下载 250px 缩略图拼图人工挑。`photo_checked` 有值的都人工看过；「候选：没找到合适的」是 Commons 上没找到拍这个景点的图。
