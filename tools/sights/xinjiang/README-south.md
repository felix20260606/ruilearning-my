# 新疆南疆 + 东疆 13 个地市景点详细版（数据源）

北疆另有一份说明（同目录其它文件，由另一个会话维护）。这里是南疆 / 东疆这 13 个：
吐鲁番 `turpan`、哈密 `hami`、新星 `xinxing`、巴音郭楞 `bayingolin`、铁门关 `tiemenguan`、阿克苏 `aksu`、阿拉尔 `aral`、图木舒克 `tumxuk`、和田 `hotan`、昆玉 `kunyu`、克孜勒苏 `kizilsu`、喀什 `kashgar`、草湖 `caohu`。

每个城市一个 `<后缀>.json`（如 `kashgar.json` → `cn-city.html?c=xinjiang-kashgar`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web xinjiang tools/sights/xinjiang`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- `from_t` 全部是「从乌鲁木齐去」：飞机 / 火车 / 自驾和大概时长。火车时长来自携程火车票页（2026-11 查询，普速 + V 字头临客，以 12306 为准）；乌尉高速（G0711，含天山胜利隧道）2025-12-26 通车，乌鲁木齐—库尔勒自驾约 3–3.5 小时。航班时长是大概数，以航司为准。
- 门票 / 开放时间 / 营业状态：主要来自携程移动版景点页（2026-11-25 抓取，`src` 里是对应链接）。写「携程显示 ¥X 起」的是平台起价，以现场为准；查不到的写「以现场为准」。
- 时效性内容（2026-11-25 核实，之后要回头改）：
  - `warn`：吐鲁番博物馆、阿斯塔那古墓（携程「暂停营业、恢复时间待定」）；哈密白石头 / 天山庙（冬季暂停）；巴音布鲁克（2026-10-12 起随独库公路冬季闭园）；楼兰故城（不开放）；库车大寺（携程显示 12-01 恢复）；喀什高台民居（暂停）；塔莎古道（暂停）。
  - 季节性：庙尔沟（携程 2027-03-01 开放）、博斯腾湖莲海世界（2027-04-30）、温宿塔村（2027-03-31）。
  - 喀什古城：主街巷全天免费开放；东门开城仪式时间引自新华社 2025 年报道（约 10:30）。
  - 帕米尔（塔县、阿克陶）：边境管理区通行证 2026-04-15 起电子证（「移民局12367」）；红其拉甫门票 + 区间车约 38.5–39.5 元是平台 / 网友信息。
- 兵团城市（新星、铁门关、阿拉尔、图木舒克、昆玉、草湖）景点少，资料也少，只写了查得到的：铁门关 1 个（铁门关关隘本身在库尔勒塔什店镇）、草湖 2 个（2026-04 新设市，写的是周边点）。
