乌鲁木齐 `urumqi`、昌吉 `changji`、五家渠 `wujiaqu`、石河子 `shihezi`、克拉玛依 `karamay`、阿勒泰 `altay`、北屯 `beitun`、塔城 `tacheng`、白杨 `baiyang`、博尔塔拉 `bortala`、双河 `shuanghe`、伊犁 `ilikazakh`、可克达拉 `kokdala`、胡杨河 `huyanghe`。

格式和做法见 `tools/sights/CITY-GUIDE.md`。改完重跑：`python3 tools/cn-data/make_city.py web xinjiang tools/sights/xinjiang`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 乌鲁木齐的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从乌鲁木齐去」。
- 兵团小城市（五家渠、北屯、白杨、双河、胡杨河、可克达拉）本地景点很少，只写了能查到的；双河、白杨、胡杨河、五家渠另加了「周边一日」（赛里木湖、怪石峪、巴克图口岸、独山子大峡谷、天山天池），内容和所在地市页重复，改的时候两边一起改。
- 门票、开放时间多数来自携程攻略页（2026-11 抓取，`src` 里是 `gs.ctrip.com/html5/you/sight/1/<id>.html`），**显示的是 11 月当天的冬季时间和冬季价格**，写成「携程显示（2026-11）…」；查不到的写「以现场为准」。塔城地区的 A 级景区介绍来自新疆文旅厅 2025-09 的塔城地区 A 级景区摸底表（PDF，见 `src`）。
