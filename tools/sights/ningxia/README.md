# 宁夏 5 个地级市景点详细版（数据源）

每个城市一个 `<后缀>.json`（如 `zhongwei.json` → 城市页 `cn-city.html?c=ningxia-zhongwei`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web ningxia tools/sights/ningxia`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 银川的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从银川去」。
- 结果：60 个手写景点（银川 15、吴忠 12、石嘴山 10、中卫 11、固原 12），22 张照片；加上 `_auto` 追加后页面上 11–19 个。
- 开放时间、门票主要来自携程移动版景点页（`gs.ctrip.com/html5/you/sight/<地区>/<id>.html`，能直接 curl，`src` 里记了网址）和去哪儿移动版搜索页，写成「约 ¥X 起（携程，以官方为准）」；查不到的写「以现场为准」。2026-11 抓取时的情况：
  - 沙坡头：携程、去哪儿都不单独售大门票（显示免费），只卖景区内交通车（约 ¥30）和各个项目。
  - 西夏陵：携程显示首道门票 ¥0（冬季免票；2025-12 至 2026-02 也免过），其它季节收费、具体价格没查到。
  - 水洞沟：携程显示首道门票限时免费，通票平台价约 ¥88–118。
  - 固原六盘山国家森林公园、野荷谷冬季闭园（携程显示 2027-04-01 / 2027-03-31 恢复），火石寨暂停营业、恢复待定，三处都写了 `warn`。**恢复开放后要删掉 warn。**
- 交通（2026-11）：银川—吴忠高铁约 32 分钟；银川—石嘴山站（大武口）动车约 21 分钟、惠农南约 38 分钟（包银高铁银川—惠农段 2024-10 开通，2025-12-23 全线贯通）；银川—中卫南约 1 小时 20 分钟起；银川—固原没有动车，普速约 5.5–6 小时。
