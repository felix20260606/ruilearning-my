# 青海 8 个市州景点详细版（数据源）

每个市州一个 `<后缀>.json`（如 `haixi.json` → 城市页 `cn-city.html?c=qinghai-haixi`；海南藏族自治州是 `hainan.json` / `qinghai-hainan`，果洛是 `golog.json`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web qinghai tools/sights/qinghai`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 西宁的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从西宁去」。
- **高原**：每个州的 `tips` 写了海拔和高反注意事项；3500 米以上的景点（果洛、玉树全部，祁连 / 门源垭口、拉脊山、橡皮山、日月山、和日石经墙等）在景点 `tips` 里写了具体海拔和高反提醒，果洛、玉树的高海拔景点 `tips` 以「高原反应风险高：」开头。海拔是常见公开数字的约数。
- 开放时间、门票主要来自携程移动版景点页（`src` 里记了网址）和去哪儿移动版，写成「约 ¥X 起（携程，以官方为准）」；查不到的写「以现场为准」。2026-11 抓取时：茶卡盐湖首道门票免费（套票 ¥108 含小火车）；塔尔寺、二郎剑约 ¥40；察尔汗含景交车 ¥75；大柴旦翡翠湖、黑独山显示免费。
- `warn`（暂时去不了，恢复后要删）：门源油菜花海（季节性，花季约 7 月）、隆务寺（暂停营业）、龙羊峡（冬季闭园，携程显示 2027-03-31 恢复）、年保玉则（暂停营业）。
- 州的归属按行政区：青海湖北岸（仙女湾、圣泉湾、金沙湾、原子城）在海北，南岸（二郎剑、黑马河、倒淌河）在海南州；日月山、丹噶尔在西宁湟源县；昆仑山口、可可西里索南达杰 / 不冻泉保护站按携程归在玉树州曲麻莱 / 治多县（G109 沿线，实际从格尔木过去）。
- 交通（2026-11）：西宁—德令哈动车约 4 小时、—格尔木约 6 小时 15 分钟（C 字头）；西宁—海东各站 15–45 分钟；玉树、果洛、黄南没有铁路。
- 结果：88 个手写景点（西宁 13、海东 11、海北 13、海南州 10、黄南 8、果洛 8、海西 14、玉树 11），48 张照片；加上 `_auto` 追加后页面上 9–29 个。
- 照片：先复用自动版的维基数据 P18，再跑 `fill_photos.py`（Commons API 429，`fill_photos_commons.py` 没跑），最后用 Commons 网页搜索（中文名加引号 + 英文名，再对没图的换英文别名搜一轮）补候选；**全部人工看过 250px 缩略图**。被否掉的记在 `photo_rejected`，例如：骆驼泉配成了罗布泊野骆驼保护区地图、佑宁寺搜出以色列拿撒勒、昂赛大峡谷搜出美国大峡谷地图、格萨尔王广场搜出香格里拉的同名广场、通天河大桥搜出的是青藏线（G109）上的另一座桥、青海湖三个湖湾只有整湖卫星图（不算）、「佑宁寺」的照片原本被自动配给了北山（已改到佑宁寺）。
- `_auto/` 改动：海西只保留路边能到的湖泊和文物点（删了 35 个无人区湖泊 / 雪山，原来 54 条）；删了放错州的「日月山」（在西宁湟源，原在海南州）、泛指的「长城」（海东，配的是金山岭）和「丝绸之路：长安—天山廊道的路网」（黄南），以及和手写重复的「喇家遗址」「柳湾遗址」「贵德玉皇阁」「和日寺石经墙及和日寺」「冬给措纳湖」「果洛红军沟」「贝大日如来佛石窟寺和勒巴沟摩崖」「达那寺」；「格萨尔三十大将军灵塔和达那寺」改名「达那寺（格萨尔三十大将军灵塔）」（不然会被「格萨尔王广场」当成重复跳过）。自动版照片人工看过，清掉 3 张：青海省民俗博物馆（是一张民国汽车老照片）、海北尕海、海西达布逊湖（地点不能确定）；湖泊卫星图保留（拍的就是该湖）。
