- 台北的 `from_t` 是「从机场 / 高铁站进城」（桃园机场、松山机场、台北车站），其余都是「从台北去」。
- 票价一律新台币（NT$），都加了「以官方为准」。台铁 2025-06-23 起调价，旧资料的台铁票价不能用。
- 每个县市的 `tips` 末尾都有一段赴台证件说明（《大陆居民往来台湾通行证》+ 签注 + 入台证；本岛旅游未全面恢复，以现行政策为准）。政策变了改 `DOCS` 那段文字即可（各文件里是同一句话）。
- 花莲：太鲁阁 2024-04-03 地震后部分开放，`city.tips` 和太鲁阁、清水断崖两条都写了 2026-11-08 公告的状态（砂卡礑、燕子口、白杨步道预计 2031 年；长春祠最早 2029 年；台 8 线时段放行），以太鲁阁国家公园官网「路况及步道」为准。光复 2025-09 马太鞍溪堰塞湖洪灾也提了一句。
- 2026-11 查到、会过期的：北投温泉博物馆 2026-11-09 起闭馆到 2027-10 底；七星山小油坑—主峰段封到 2027-01-19；故宫翠玉白菜 2026-12-08 至 2027-03-07 在南院；福隆海水浴场 2026-10 台风后关闭；龟山岛 2026 年登岛季到 11-30、401 高地步道关闭；太平山蹦蹦车只跑 1 公里、见晴步道只开到 750 米；猫空缆车一般周一停驶。
- 主要信息来源：insidetaipei.com / insideyilan.com / insidehsinchu.com / insidehualien.com（2026-10、11 月核对过官方信息的英文指南，`src` 里有的直接链过去）、各县市观光官网、携程景点页。
