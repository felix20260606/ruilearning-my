# 河北 11 个地级市景点详细版（数据源）

每个城市一个 `<后缀>.json`（如 `chengde.json` → 城市页 `cn-city.html?c=hebei-chengde`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web hebei tools/sights/hebei`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 石家庄的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从石家庄去」。承德、秦皇岛、张家口、廊坊、保定、唐山、沧州的 `from_hz` 末尾顺带写了从北京怎么去。
- 交通按 2026-11 的情况写（车次少的都写了「以 12306 为准」）：
  - 石家庄—张家口没有直达高铁，写的是北京换京张高铁（或经太原、大同约 5 小时的直达动车）。
  - 石家庄—承德南、石家庄—秦皇岛、石家庄—廊坊每天只有少量直达高铁；石家庄—沧州西有少量直达车（经衡水北，约 2 小时 15 分钟）。
  - 衡水—沧州—黄骅港的**衡港高铁**在 2026-10 进入运行试验，沧州页写的是「开通后会更方便」——**开通后要改沧州（和衡水）的 from_hz**。
  - 河北博物院：2026-11 官方公告开放时间 09:00–17:00（16:30 停止入馆），实名预约。
- 门票多数是大河票务网（dahepiao.com，文章页能直接 curl）、携程、去哪儿的平台价，写成「约 ¥X（…，以官方为准）」；查不到的写「以现场为准」。避暑山庄旺季 ¥130、外八庙联票、白洋淀套票、山海关三景点等来自大河票务网 / 去哪儿 2025 价。
- 结果：11 个市 115 个手写景点（石家庄 12、邢台 9、衡水 8、保定 12、邯郸 11、沧州 8、廊坊 8、张家口 11、唐山 11、承德 12、秦皇岛 13），73 张照片；加上 `_auto` 追加后页面上 9–61 个景点。
- 照片：先复用自动版的维基数据 P18，再跑 `fill_photos.py`、`fill_photos_commons.py`，最后用 Commons 网页搜索补候选；**全部人工看过 250px 缩略图**。`photo_checked` 有值的都人工看过；「自动找到的不对，留空」的在 `photo_rejected` 记了被否掉的文件名（例如老虎石配成了大连老虎滩、李大钊故居配成了唐山交大、碣石山配成了广东陆丰碣石、雾灵山配成了台湾武陵）。
- `_auto/` 改动：删了放错地方的「九门口」（辽宁绥中，原在秦皇岛）、「临清运河钞关」（山东，原在衡水）、「延庆古崖居」（北京，原在张家口）、泛指的「长城」（廊坊）；删了和手写重复的「中山靖王墓」（＝满城汉墓）、「正定城」、「广府镇」「广府城」「赵邯郸故城」、「唐山大地震遗址」「开滦唐山矿早期工业遗存」。自动版照片 70 张人工看过，7 张是文物 / 拓片 / 地图，已清空（中山王墓、燕下都、王处直墓、两处道德经幢、京杭大运河、磁山遗址）。
