# 山东 16 个地级市景点详细版（数据源）

每个城市一个 `<后缀>.json`（如 `qingdao.json` → 城市页 `cn-city.html?c=shandong-qingdao`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web shandong tools/sights/shandong`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 济南的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从济南去」。
- 交通按 2026-11 的情况写：
  - 济南地铁 3 号线二期 2024-11-22 通到遥墙机场（机场南站），济南东站到机场约 21 分钟。
  - 济郑高铁济濮段 2023-12 开通：济南西—聊城西最快约 32 分钟。
  - 潍烟高铁 2024 年开通：济南东—烟台最快约 2 小时，经莱州、招远、蓬莱。
  - 青岛地铁 8 号线 2026-09-22 全线通车：五四广场—胶东机场快车约 40 分钟、¥7。
  - 济滨高铁（济南东—遥墙机场—济阳—商河—惠民—滨州）2026-11-25 联调联试结束进入试运行，计划年底开通——滨州页写的是「计划年底前开通，以铁路公告为准」，**开通后要改滨州的 from_hz**。
  - 津潍高铁（经滨州、东营）在建，报道计划 2027 年通车；东营目前没有直达济南的高铁（K 车约 3 小时或淄博换乘）。开通后要改东营、滨州。
- 门票多数查到的是携程 / 去哪儿 / 大河票务的平台价，写成「约 ¥X（以官方为准）」；查不到的写「以现场为准」。三孔、泰山、刘公岛、崂山、小鱼山、海军博物馆等旺季要实名预约，已写进 tips。
- 照片：2026-11 做的时候中文维基 API 一直 429，没跑 `fill_photos.py`；先人工看了自动版带过来的照片（8 张不对已清空），其余用 Commons 搜索给每个景点找几张候选，下载 250px 缩略图拼图人工挑。
  `photo_checked` 有值的都人工看过；「候选都不对，留空」的是看过但没有合适的；「候选：没找到」的是 Commons 上没搜到任何候选（以后可以再找）。
- 结果：16 个城市 177 个手写景点（每城 8–15 个）、99 张照片，全部人工看过缩略图（其中 30 张沿用自动版；自动版原有 38 张，8 张不对已清空：黄河口那张是城里的嬉水公园、龟蒙那张是天蒙景区、八大关那张是海大的俾斯麦兵营、殉马馆那张是临淄城模型等）。
- `_auto/` 改动：删了和手写重复的 11 条（济南「济南纬二路近现代建筑群」「济南万竹园」、泰安「泰山古建筑群」「泰山石刻」、聊城「景阳岗遗址」、青岛「青岛奥林匹克帆船中心」、潍坊「东镇庙」、烟台「蓬莱水城」「张裕公司酒窖」「烟台福建会馆」、菏泽「百寿坊及百狮坊」），以及放错城市的 2 条：日照「京杭大运河」、德州「长城」。
