# 黑龙江 13 个市 / 地区景点详细版（数据源）

每个城市一个 `<后缀>.json`（如 `mudanjiang.json` → 城市页 `cn-city.html?c=heilongjiang-mudanjiang`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web heilongjiang tools/sights/heilongjiang`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 哈尔滨的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从哈尔滨去」。大兴安岭的文件叫 `daxinganling.json`（slug `heilongjiang-daxinganling`，zh「大兴安岭地区」）。
- 归属容易弄错的：雪乡（海林市双峰林场）放牡丹江；亚布力（尚志市）、萧红故居（呼兰区）属哈尔滨；五大连池放黑河；嘉荫恐龙地质公园放伊春（不是鹤岗）；珍宝岛（虎林市）放鸡西；抚远黑瞎子岛 / 东极广场、同江三江口放佳木斯；饶河四排赫哲族乡放双鸭山。
- 冰雪项目写了季节和大概月份，每年日期以官方公告为准（2026-11 的情况）：
  - 哈尔滨冰雪大世界第 28 届：官方说 2026 年 12 月中旬开园，日期和票价开园前几天才公布；第 27 届成人票 ¥328，2026-02-21 因升温提前闭园。
  - 太阳岛雪博会第 39 届、松花江冰雪嘉年华第 9 届同期；兆麟公园第 53 届冰灯游园会 2026-12-30 开放，免费。
  - 亚布力 2026–2027 雪季 11-01 试滑、11-06 开板；雪乡 2026–2027 雪季 11-19 开园，全面实名预约。
  - 镜泊湖冬捕节一般 1 月中旬；连环湖冬捕（冰雪渔猎那达慕）约 12 月下旬到 2 月；漠河冬至文化节 12 月 21 日前后。
- 交通（2026-11）：哈伊高铁 2026-09-28 开通（哈尔滨—绥化南—庆安—铁力—伊春西，哈尔滨到伊春西最快 1 小时 46 分）；哈牡高铁 2018-12、牡佳高铁（牡丹江—林口南—鸡西西—七台河西—双鸭山西—佳木斯）2021-12-06 开通；哈尔滨到鹤岗有直达 C 字头动车约 3 小时 45 分；哈尔滨到抚远没有直达火车，要在佳木斯转普速；饶河没有铁路和机场；哈尔滨到漠河是 K7039 / K7041 夜车约 17 小时。哈尔滨地铁 3 号线 2024-11 闭环运营，太平机场没有地铁。
- 门票：官方公告的写死（如 731 陈列馆免费预约、北极村 ¥88、五大连池温泊 ¥40 / 龙门石寨 ¥45 / 北药泉 ¥20 旺季价），平台价写成「约 ¥X（以官方为准）」，查不到的写「以现场为准」。七台河、鹤岗、绥化等小城很多景点查不到门票和时间。
- `_auto/` 改动：删了外省的「宣化柏林寺」（河北）、「他拉红泡」（吉林），删了大庆 13 个没有旅游设施的小水泡（东风泡、中内泡、喇嘛寺泡、新华湖、月饼泡等），删了和手写重复的大庆「大庆第一口油井」（= 松基三井）、齐齐哈尔「蒲与路故城遗址」、哈尔滨「伪满洲国哈尔滨警察厅旧址」（= 东北烈士纪念馆）、「哈尔滨莫斯科商场旧址」（= 黑龙江省博物馆）和黑河重复的「五大连池世界地质公园」；清掉 4 张错图：牡丹江「中东铁路建筑群」（其实是哈尔滨滨洲铁路桥）、鸡西「小兴凯湖」（卫星图）、鹤岗「奥里米城址」和绥化「八里城遗址」（文物特写）。
- 照片：2026-11 做的时候 Commons API 很快就 429，改用 Commons Special:Search 网页（中文名、英文名各搜一次，`filetype:bitmap`）找候选，下载 250px 缩略图拼图人工挑。`photo_checked` 有值的都人工看过；「候选都不对，留空」是看过但没有合适的；「候选：没找到合适的」是 Commons 上没搜到拍这个景点的图。
- `src`：zh.wikipedia 链接都用 curl 检查过存在。
- 结果（2026-11-25）：13 个市 / 地区 116 个手写景点（哈尔滨 15、齐齐哈尔 12、黑河 11、大庆 10、牡丹江 10、佳木斯 9、绥化 9、伊春 8、大兴安岭 8、鸡西 7、鹤岗 7、七台河 5、双鸭山 5），58 张照片全部人工看过缩略图；自动版追加进来的旧照片也看过。七台河、鹤岗、绥化在 Commons 上找不到拍这些景点的图，留空。
