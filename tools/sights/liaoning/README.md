# 辽宁 14 个地级市景点详细版（数据源）

每个城市一个 `<后缀>.json`（如 `dalian.json` → 城市页 `cn-city.html?c=liaoning-dalian`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web liaoning tools/sights/liaoning`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 沈阳的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从沈阳去」；大连的 `from_hz` 另写了周水子机场、大连北站 / 大连站进城。
- 2026-11 做的，交通按当时情况写：
  - 沈阳地铁 2 号线 2023-09 通到桃仙机场（T3 地下一层）；1 号线东延 2025-06-30 开通（东陵公园站、植物园站）；3 号线东段 2026-06-30 开通。
  - 沈白高铁 2025-09-28 开通：沈阳北—抚顺（原抚顺北站，2025-05-30 复名抚顺站）约 18 分钟、—新宾（去赫图阿拉、永陵）约 47–60 分钟。**不经过本溪、桓仁**，桓仁（五女山）只有大巴 / 自驾。
  - 朝阳的高铁站叫「辽宁朝阳站」（京哈高铁，2020-11 改名），另有牛河梁站、喀左站；阜新站（原阜新北站）。
  - 盘锦：沈阳北—盘锦北约 1 小时但离市区约 30 公里；沈阳站有车直达市区的盘锦站（盘营高铁）。
  - 大连金州湾新机场在建，目前仍用周水子机场（地铁 2 号线）。
- 门票多数是携程 / 去哪儿 / 大河票务的平台价，写成「约 ¥X（以官方为准）」；查不到的写「以现场为准」（沈阳故宫单票、北陵 / 东陵、抚顺几处纪念馆等，平台只有套票）。
- 2026-11 暂停营业 / 冬季闭园、写进了 hours 或 tips 的：大连发现王国（没单列）、丹东天桥沟、营口赤山、本溪望天洞 / 枫林谷、关门山部分区域、锦州笔架山（约 4–11 月开）、抚顺红河谷漂流（夏季）。锦州世博园（2026-10-15 起闭园修整）、关东葫芦古镇、鼎翔、苇海蟹滩、锦州市博物馆显示暂停营业，没收，只在城市 tips 里提到。
- 照片：Commons API 当时 429，用 Commons Special:Search 网页 + 中文维基条目里的图找候选，下载 250px 缩略图拼图人工挑。
  `photo_checked` 有值的都人工看过；「候选都不对，留空」是看过但没有合适的（多是外省同名：抚仙湖月亮湾、广州白云山、广东观音山、河南平顶山、杭州凤凰山等）；「候选：没找到」是 Commons 上没搜到（以后可以再找）。
