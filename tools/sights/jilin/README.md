# 吉林 9 个市州景点详细版（数据源）

每个城市一个 `<后缀>.json`（如 `yanbian.json` → 城市页 `cn-city.html?c=jilin-yanbian`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web jilin tools/sights/jilin`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 长春的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从长春去」。吉林市的文件叫 `jilin.json`（slug `jilin-jilin`）。
- 长白山分三个坡、分开售票：北坡（天池、长白瀑布）放在延边（安图县二道白河，`yanbian.json`），西坡和南坡放在白山（抚松县、长白县，`baishan.json`）。宝马城（金代长白山神庙遗址）也在延边。
- 交通按 2026-11 的情况写：
  - 沈白高铁（沈阳北—通化—白山东—江源东—长白山西—长白山）2025-09-28 开通；原松江河站 2025-03 改名长白山西站（西坡门户）。长春到白山没有直达，要在吉林或敦化换乘。
  - 长春轨道交通 7 号线一期 2026-08-26、5 号线一期 2026-09-28 开通；空港线（9 号线）在建，龙嘉机场进城靠长吉城际龙嘉站、机场大巴。
  - 长春 → 延吉西约 2 小时 10–30 分钟；长春 → 长白山站最快约 2 小时 20 分钟；长春 → 松原城际约 1 小时 10–20 分钟；长春 → 白城约 2 小时 40 分钟；长春 → 通化最快约 2 小时 45 分钟；通化 → 集安普快约 2 小时 50 分钟（集安没有高铁）。
- 门票：长白山三个坡门票 ¥105、环保车 ¥85（官方购票问答）；北坡天池主峰车 ¥80，2026 年起镇区到山门班线车 ¥25；伪满皇宫 ¥70（2026 春节公告）。其余多是携程 / 去哪儿 / 大河票务的平台价，写成「约 ¥X（以官方为准）」；查不到的写「以现场为准」。
- 照片：2026-11 做的时候中文维基和 Commons 的 API 都 429，没跑 `fill_photos*.py`；改用 zh.wikipedia 条目网页里的 File: 链接 + Commons Special:Search 网页（中文加引号、英文名各搜一次）找候选，下载 250px 缩略图拼图人工挑。
  `photo_checked` 有值的都人工看过；「候选都不对，留空」是看过但没有合适的；「候选：没找到合适的」是 Commons 上没搜到拍这个景点的图（以后可以再找）。
- 结果：9 个市州 94 个手写景点（每城 8–14 个）、57 张照片，全部人工看过缩略图；自动版追加进来的 5 张旧照片（伪满忠灵庙、伪满中央银行、长春方志馆、吉林西站、红石砬子）也看过，没问题。
- `_auto/` 改动：删了和手写重复的 6 条（通化「高句丽王城、王陵及贵族墓葬」「丸都城」「洞沟古墓群」、延边「六顶山古墓群」、长春「长影集团」、吉林市「吉林耶稣圣心堂」）；长春「中东铁路建筑群」原来挂的是哈尔滨滨洲铁路桥的照片，已清空。
- `src`：zh.wikipedia 链接都用 curl 检查过存在（不存在的已换成相关条目或携程 / 新闻页）。
