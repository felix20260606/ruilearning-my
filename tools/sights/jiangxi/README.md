# 江西 11 个市景点（手写详细版）

- 每个市一个 `<城市后缀>.json`（南昌 九江 景德镇 上饶 鹰潭 抚州 宜春 新余 萍乡 吉安 赣州），格式见 `tools/sights/CITY-GUIDE.md`。抚州是 `fuzhou.json`（江西抚州，别和福建福州弄混）；吉安是 `jian.json`。
- `_auto/`：做手写版之前的维基数据自动版留底；生成时手写里没有的景点会追加在后面。已去掉和手写重复的（流坑村古建筑群、南粤雄关与古道、瑞金革命遗址、渼陂红四军总部旧址、浮梁县衙、镇窑、高岭瓷土矿遗址、庐山会议旧址及庐山别墅建筑群、庐山第四纪冰川国家地质公园、清华彩虹桥、汪口俞氏宗祠）；清掉了错图：龙源口桥挂的是人民币图案 gif、万安城墙挂的是赣州城墙、樊城堆遗址挂的是位置图，以及 11 张只拍了文保碑牌子的照片。
- 南昌 `from_t` 是「从机场 / 高铁站进城」，其它城市是「从南昌去」。
- 上山 / 索道：庐山、三清山（上饶）、龙虎山（鹰潭）、婺源篁岭（上饶）、井冈山（吉安）、武功山（萍乡金顶 + 吉安羊狮慕）都写了上山方式和索道价（多为 2025–2026 年平台 / 攻略价，标了「以官方为准」）。武功山露营、徒步提醒写在萍乡「武功山金顶」「武功山徒步穿越」两条的 tips 里。
- 照片：先复用 `_auto` 里维基数据的图（`photo_from="wikidata-auto:…"`），其余从 Commons 搜索候选里挑，全部人工看过 250px 缩略图（`photo_checked`）。
- 查不到的门票 / 开放时间写「以现场为准」或「以官方为准」。
