# 贵州 9 个市州景点详细版（数据源）

9 个市州共 99 个手写景点、52 张照片（2026-11）。每个市州一个 `<后缀>.json`（如 `zunyi.json` → 城市页 `cn-city.html?c=guizhou-zunyi`），格式和做法见 `tools/sights/CITY-GUIDE.md`。
改完重跑：`python3 tools/cn-data/make_city.py web guizhou tools/sights/guizhou`（`_auto/` 是维基数据自动版留底，手写里没有的会追加在后面）。

- 贵阳的 `from_t` 是「从机场 / 高铁站进城」，其余都是「从贵阳去」。
- 交通按 2026-11 的情况写：盘兴高铁 2025-11-28 开通（盘州—保田—兴义南，贵阳北—兴义南最快约 1 小时 56 分），贵州「市市通高铁」；贵南高铁（2023-08）到荔波、平塘；成贵高铁到黔西、大方、毕节。
  赤水、习水、仁怀不通高铁（先到遵义再转车）；镇远没有高铁站（普速镇远站或凯里南转车）；从江站在黎平县洛香镇，离肇兴近、离从江县城远。
- 花江峡谷大桥（2025-09-28 通车，世界第一高桥）放在黔西南；北盘江第一桥（六盘水）写成「通车时是世界最高桥」。
- 二十四道拐观景台、展览馆 2026-10-03 起免门票（晴隆县通报）。
- 门票多数是票务平台价，写成「约 ¥X（以官方为准）」；查不到的写「以现场为准」。遵义会议会址 2026 年修缮后开放安排以纪念馆公告为准。
- 没写进去的：黔东南隆里古城（查不到票价 / 开放时间，_auto 里有「隆里古建筑群」）、黔南斗篷山（平台显示暂停营业）、三都姑鲁产蛋崖（确认不了是否开放）、六盘水盘州古城、毕节大屯土司庄园（_auto 里有）。
- `_auto/` 删了和手写重复的：安顺「云山屯古建筑群」、黔西南「二十四道拐抗战公路」、遵义「中国丹霞」「赤水丹霞地貌」「红军四渡赤水战役旧址」「湄潭浙江大学旧址」「茅台酒酿酒工业遗产群」、铜仁「寨英村古建筑群」「楼上村古建筑群」、黔南「福泉城墙」。
- 照片：Commons 网页全文搜索找候选 + 250px 缩略图拼图人工挑。`photo_checked` 有值的都人工看过；「候选都不对，留空」是看过但没有对的；没写 `photo_checked` 的是没找到候选。
